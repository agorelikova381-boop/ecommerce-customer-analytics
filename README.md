# Анализ клиентской базы e-commerce

Самостоятельный учебный проект по маркетинговой и продуктовой аналитике на открытых обезличенных данных маркетплейса Olist.

## Цель

Понять структуру клиентской базы, динамику ключевых метрик, повторные покупки и факторы клиентского опыта, чтобы сформулировать проверяемые маркетинговые гипотезы.

## Данные

[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) — около 100 тыс. заказов за 2016–2018 годы. В анализе используются таблицы заказов, оплат, клиентов, товаров и отзывов. Данные обезличены.

## Дизайн исследования

Анализ отвечает на четыре вопроса:

1. Как устроена база заказов и какие метрики описывают бизнес?
2. Какие клиентские сегменты отличаются по давности, частоте и сумме покупок?
3. Как меняется доля повторных покупок после первого заказа?
4. Связаны ли оценки заказов с дальнейшим поведением покупателей?

Для ответа использованы проверка качества данных, расчёт KPI, RFM-анализ, когортный анализ, кластеризация K-Means и анализ отзывов. Результаты являются описательными: чтобы подтвердить причинные связи, нужны отдельные эксперименты.

## Что сделано

- проверка качества данных и логические фильтры для расчёта метрик;
- расчёт GMV, числа заказов, среднего чека и топ-категорий;
- RFM-сегментация и когортный анализ повторных покупок;
- кластеризация клиентов методом K-Means;
- анализ клиентских оценок и формулирование гипотез для A/B-тестов.

## Основные результаты

- За период в данных — 96 477 заказов; GMV составил 15,4 млн, средний чек — 159,9.
- RFM-анализ и кластеризация позволили выделить сегменты клиентов с разной ценностью и частотой покупок. Это может стать основой для персональных коммуникаций.
- Когортный анализ показал низкую наблюдаемую долю повторных покупок в первые месяцы. На результат могут влиять ограниченное окно наблюдения и особенности товарных категорий, поэтому это не следует интерпретировать как установленную причину оттока.
- 77,1% отзывов имеют оценки 4–5, но высокая оценка конкретного заказа сама по себе не гарантирует повторную покупку.
- Отдельного изучения требует группа клиентов с оценками 1–2: для неё можно проверить гипотезу о влиянии персональной коммуникации после покупки на повторную покупку в эксперименте с контрольной группой.

## Итоговый вывод

Анализ показывает, что потенциальная точка роста для e-commerce — работа с повторными покупками. Сегментация помогает выбрать разные сценарии коммуникации для клиентов с разной ценностью, а негативные оценки — выделить аудиторию, для которой особенно важно проверить поддержку и персональные предложения. При этом исторические данные не позволяют установить причину низкого retention: следующие решения нужно проверять через контролируемый эксперимент.

## Инструменты

Python, pandas, DuckDB, scikit-learn, matplotlib, seaborn.


## Ограничения

Датасет учебный и обезличенный. Выводы нельзя переносить на другой бизнес без дополнительной проверки и эксперимента.
